# DEV-REQUIREMENTS · 小嗜宝 EosPal

版本 v0.1.0 · 夜间无人值守模式：无提问、不停等，默认值落本文件 §五，晨审追认。

## 一、患者视角红线

- 功能按患者关心的信息维度组织：发作规律、化验趋势、饮食诱因、按次用药、复诊准备。医生任务（分型判定、治疗方案选择）不冒充患者功能。
- 0 患者访谈、0 临床审核必须标注在 SPEC/USER-RESEARCH/README。

## 二、事实与演示数据唯一源

- 演示数据唯一源：prototypes/v0.2/demo-data.js（两套合成档案 A/B）；服务端种子与测试读同一份。
- 医学事实唯一源：docs/CLINICAL-DATA.md + docs/SOURCES.md 证据台账；阈值与参考区间一律【待核】。

## 三、禁区（非肿瘤）

- 禁词：病期、线序、疗效、预后、生存期、复发判定、匹配指数、diagnosis/risk_level 列。
- 表达替换：发作—缓解区间带、缓解期第 N 天/发作中第 N 天、距上次发作 N 天、近 90 天发作次数。
- 界面不替医生说话：紧急口径只呈现医生已确认原话，或空态引导去问医生。

## 四、工程纪律

- 改包必升版；public 与原型 ui-parity；隐私三出口代码级过滤；ORDER BY rowid、显式 null、无判读列。
- 版本十处同源；check/test/audit 全绿；SKIP 不计覆盖。
