## 问题、用户与最小闭环

- 服务主体：嗜酸性粒细胞性胃肠炎（EGID）患者及照护者。
- 核心问题：症状（腹痛/腹泻/恶心/腹胀）反复发作，散落在多家机构的化验单（外周血嗜酸粒细胞、白蛋白等）与内镜/病理报告（活检嗜酸粒细胞 /HPF）无法对照；饮食剔除与按次用药（激素疗程、抗组胺）记录零散；内镜复查与复诊前缺少准备材料。
- 最小闭环：记录一次发作/缓解事件 → 核对入库 → 查看嗜酸粒细胞趋势与发作—缓解区间带 → 生成复诊问题清单与就医准备材料。
- 成功标准：全部展示数据可追溯到一条本机记录（来源、日期、机构）；不出现任何诊断/分型/预后判定；两套合成档案 A/B 切换整页联动不串档。

## 方案与 ADR

- 布局沿用家族 40 号 A 面板标准（business-first，中间主区 + 右侧 Agent 面板）。
- 病程模型采用「发作—缓解 + 按次事件」而非「分期/线序」：EGID 为非肿瘤慢性病，家族 1.3 表明确禁用病期/线序/疗效语义。ADR-1：以「一次发作」「一次调药」「一次内镜检查」为折叠与时间线单元。
- 指标线以「外周血嗜酸粒细胞绝对计数」为主指标、「内镜活检嗜酸粒细胞 /HPF」为按次登记（不同来源不可合并连线），ADR-2：活检 /HPF 不进连续趋势图，只做按次卡片与事件泳道，避免与外周血计数混标。

## 数据与 API

实体：档案、发作/缓解事件、化验记录（外周血）、内镜/活检按次记录、按次用药与饮食记录、复诊问题、就医信息（多医院）。详见 docs/SCHEMA.md（M3 冻结）。
外部信息合同：疾病概要四段（36 号）来源按「原件/官方入口/二次来源/nolink+note」四态标注；未取得原件写「未取得原件，据二次来源」。化验参考区间一律【待核】，以医生安排为准。治疗全景段固定出口口径：按受累器官与病情轻重排列（非肿瘤），并含「不代表任何一项适合你」「需要问你的医生」。
