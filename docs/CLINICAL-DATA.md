# CLINICAL-DATA · 小嗜宝 EosPal 临床数据口径

版本 v0.1.0 · **0 临床审核——全部阈值/参考区间为【待核】占位，以医生安排为准。**

## 内容边界（指南只定边界，不转自测、不选治疗）

- 来源：《86 个罕见病病种诊疗指南（2025 年版）》嗜酸性粒细胞性胃肠炎章节（二次来源，原件未取得时如实标注）；国际消化病学共识作内容边界参考（不用于中国适应证口径）。
- 界面只呈现：医生已确认原文、化验数值与日期、按次事件事实。不生成：分型判定、治疗方案、疗效结论。

## 指标体系（按随访维度分 5 组；全部参考区间【待核】）

| 组 | 指标 | 单位 | 说明 |
| --- | --- | --- | --- |
| 嗜酸粒相关 | 外周血嗜酸粒细胞绝对计数 | ×10⁹/L | 主趋势指标；跨机构方法不合并 |
| 嗜酸粒相关 | 外周血嗜酸粒细胞百分比 | % | 与绝对计数同组不连线 |
| 血象 | 白细胞计数、血红蛋白 | ×10⁹/L、g/L | 常规随访 |
| 营养与并发症 | 白蛋白、总 IgE（如医生开单） | g/L、IU/mL | 缺项允许未知 |
| 内镜活检 | 活检嗜酸粒细胞计数 | 个/HPF | 按次登记（ADR-2 不进连续趋势） |

## 随访与求助短语

- 内镜复查节律：只呈现医生已确认安排原话；无原文时空态引导「问医生下次复查时间」。
- 紧急口径：「若医生告知过出现 X 联系 Y」——只照抄行动计划原话，无原文不显示。
- 禁止：复发判定、自动分型、缓解/加重自动分级、任何阈值自动告警（23 号分级仅作 M1 文档边界，不进自测）。

## 试验线数据（M4）

- 通道：本地快照 + unified-trial-mcp 在线（双通道）；FAILED/DENIED 不算查过、不计覆盖，如实记录。
- 快照字段只存登记的结构化字段；入排原文不抓取，展示「请到官方登记页核对」。
