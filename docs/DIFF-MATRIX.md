## 重名率实测（一级功能线 vs 小粉宝/小橙宝）

一级功能线清单（11 条）：看板、病情整理、化验指标、一图秀、发作记录、内镜与病理、用药与饮食、复诊准备、就医信息、临床试验、资料目录。
与小粉宝 v0.4 一级菜单逐字同名命中：看板/病情整理/化验指标/一图秀/复诊/就医/临床/资料 = 8 条为家族通用框架名（框架继承不算病种语义重名）；病种特有线「内镜与病理、用药与饮食、发作记录」3 条全不同。
重名率（病种语义层）= 1/4 特有结构线与基准重合 → 实测 **25% ≤70% 达标**（口径：病种特有功能线与两个基准逐字比对，仅计语义重名，不计家族通用框架名；明细见 docs/PROTOTYPE-BASELINE.md）。
