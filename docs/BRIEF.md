# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：嗜酸性粒细胞性胃肠炎患者及照护者；核心诉求是弄清发作规律、嗜酸粒细胞（外周血/内镜活检）趋势、饮食诱因与按次用药记录，内镜复查与复诊时能带着清单与医生对话

场景：腹痛、腹泻、恶心等胃肠症状反复发作与缓解交替，患者最关心现在缓解第几天、距上次发作多久、近 90 天发作几次；外周血与内镜活检嗜酸粒细胞计数散落多家机构需要长期趋势但不同方法/单位不可比；激素疗程、抗组胺按次用药与饮食剔除试验要逐条记录；内镜复查前需要就诊准备、饮食记录与问题清单（认领 Issue #64，罕见病目录 #134）

核心流程：
1. 选择本机资料目录并导入化验/内镜/病理报告
2. 记录一次发作或缓解事件，核对入库
3. 登记按次用药（激素/抗组胺等）与饮食剔除记录
4. 查看嗜酸粒细胞计数趋势与发作—缓解区间带
5. 生成内镜复查与复诊准备材料、问题清单

完成结果：得到来源可追溯、可核对的个人病程档案：发作—缓解事件带、嗜酸粒细胞计数趋势（含内镜活检按次登记）、按次用药与饮食记录、复诊问题清单与多医院就医信息；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
